# desafio-poewrbi-dio-mateu
Desafio 2 da dio.me: Analisando dados com SQL Analytics e Power BI

Este repositório contém o objetivo principal do projeto é realizar o tratamento e a análise visual de dados de vendas para gerar *insights* estratégicos de negócio.

## Objetivo do Projetos

Construir um relatório interativo no Power BI a partir de uma base de dados de vendas (Financial Sample), aplicando boas práticas de ETL (Power Query), modelagem de dados e criação de métricas em DAX.
